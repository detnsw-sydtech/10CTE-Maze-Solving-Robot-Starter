# Maze-Solving Robot Project Brief
Year 10 Computing Technology  
Sydney Technical High School

## Overview
In this project, you will design, build, and program a robot capable of navigating
from the centre of a maze to the exit using a deterministic algorithm. You will
use the Keyestudio Ultimate Starter Kit Robot Car Kit and the Arduino-based
Keyestudio PLUS board.

This project integrates mechatronics, electronics, algorithms, and engineering
documentation. It is designed for high-ability students and aligns with Stage 5
Computing Technology outcomes.

## What You Will Build
A fully functioning maze-solving robot that uses:
- **Ultrasonic sensing** for detecting walls ahead  
- **IR obstacle sensors** for detecting left and right walls  
- **DC motors + motor driver** for motion control  
- **Left-Hand Rule algorithm** for deterministic maze navigation  
- **Modular Arduino code** for maintainability and clarity  

## Learning Outcomes
You will learn:
- Mechatronic system design  
- Electronic wiring and power distribution  
- Sensor integration and calibration  
- Deterministic maze-solving algorithms  
- Modular Arduino programming  
- Engineering testing and iteration  
- Technical documentation and reflection  

## Success Criteria
Your robot must:
1. Start in the centre of a maze  
2. Navigate using the Left-Hand Rule  
3. Avoid collisions  
4. Reach the exit reliably  
5. Demonstrate stable movement and correct sensor behaviour  
6. Be fully documented in your project portfolio  

## Constraints
- Robot must fit within maze corridors  
- Only components from the Keyestudio kit may be used  
- No remote control or manual intervention  
- Code must be modular and readable
