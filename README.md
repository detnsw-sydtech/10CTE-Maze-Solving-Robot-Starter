# Maze-Solving Robot (Keyestudio Kit)
Year 10 Computing Technology  
Sydney Technical High School  

This project guides you through building and programming a robot that can
navigate from the centre of a maze to the exit using the Left-Hand Rule
algorithm.

## Learning Outcomes
- Mechatronics systems (sensors, actuators, controllers)
- Electronics wiring and power distribution
- Arduino programming and modular code design
- Deterministic maze-solving algorithms
- Engineering testing and documentation

## How to Use This Repo
1. Read all documents in /docs
2. Build your robot using the hardware guide
3. Wire sensors and motors according to the wiring diagram
4. Complete the code in /src
5. Run tests in /tests
6. Submit your final robot and documentation
