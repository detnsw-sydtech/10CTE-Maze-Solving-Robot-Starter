# Teacher Assessment Pack  
### Maze-Solving Robot — Year 10 Computing Technology  
### Sydney Technical High School  

This pack provides teachers with everything needed to assess, moderate, and support student submissions for the Maze-Solving Robot project.

---

## 1. Assessment Overview

Students design, build, and program a robot capable of navigating a maze using the Left-Hand Rule algorithm. Assessment includes:

- Hardware construction  
- Algorithm implementation  
- Code quality  
- Testing & debugging  
- Documentation  
- Engineering reasoning  

---

## 2. Evidence Required

Students must submit:

1. **Working robot**  
2. **Engineering portfolio**  
3. **Arduino source code**  
4. **Testing logbook**  
5. **Reflection**  

Optional (for Band 6 extension):
- Video demonstration  
- Additional features (PID, multi-sensor array, speed optimisation)

---

## 3. Teacher Checklist

### Hardware
- Motors wired correctly  
- Sensors placed correctly  
- Power distribution stable  
- No loose connections  
- Chassis assembled cleanly  

### Code
- Modular structure  
- No redundant logic  
- Clear comments  
- Correct algorithm behaviour  

### Documentation
- Wiring diagram  
- Flowchart  
- Pseudocode  
- Testing evidence  
- Reflection  

---

## 4. Common Student Errors

- Incorrect IR sensor orientation  
- Ultrasonic sensor mounted too high  
- Missing common ground  
- Blocking code using `delay()`  
- Incorrect threshold values  
- Turning logic reversed  

---

## 5. Teacher Support Notes

- Encourage students to use Serial Monitor early and often.  
- Require students to keep an engineering logbook.  
- Reinforce modular code structure.  
- Provide maze test environments with increasing complexity.  

---

## 6. Safety Notes

- Ensure battery polarity is correct.  
- Check for exposed wires.  
- Avoid running robots near edges or stairs.  

---

## 7. Final Submission Requirements

Students must submit:

- `/src` folder  
- `/docs` portfolio  
- Video (optional)  
- Completed reflection
