# Maze-Solving Robot — Hybrid Marking Rubric  
### Year 10 Computing Technology  
### Sydney Technical High School  

This rubric combines **analytic marking** (criteria × marks) with a **holistic band judgement** to support NESA‑aligned moderation and consistent teacher assessment.

---

# 🟦 **A. Analytic Criteria (70 marks total)**

| Criterion | Description | Marks |
|----------|-------------|-------|
| **Hardware Construction** | Wiring quality, sensor placement, mechanical stability, power distribution discipline | **20** |
| **Algorithm Implementation** | Correct Left-Hand Rule logic, deterministic behaviour, correct handling of junctions and dead ends | **20** |
| **Code Quality** | Modular structure, readability, comments, naming conventions, absence of redundancy | **15** |
| **Testing & Debugging** | Evidence of systematic testing, engineering logbook entries, iteration based on test results | **10** |
| **Documentation** | Portfolio completeness, wiring diagrams, flowcharts, reflection, clarity of communication | **5** |

---

# 🟦 **B. Holistic Grade (30 marks)**  
Assesses overall engineering maturity, coherence, and reliability of the final robot and documentation.

### **Band 6 (25–30 marks)**  
- Robot navigates maze reliably and consistently  
- Algorithm is implemented cleanly and behaves deterministically  
- Code is modular, well‑structured, and professionally documented  
- Testing is thorough, systematic, and clearly informs improvements  
- Documentation is complete, clear, and demonstrates engineering reasoning  

### **Band 5 (18–24 marks)**  
- Robot completes maze with minor inconsistencies  
- Algorithm mostly correct with occasional misinterpretations  
- Code is mostly modular with minor structural issues  
- Testing present but not fully systematic  
- Documentation clear but missing depth or detail  

### **Band 4 (10–17 marks)**  
- Robot shows partial maze navigation  
- Algorithm incomplete or inconsistently applied  
- Code functional but not modular or well‑documented  
- Limited testing evidence  
- Documentation incomplete or unclear  

### **Band 3 (0–9 marks)**  
- Robot does not navigate maze  
- Algorithm missing or incorrect  
- Code incomplete or non‑functional  
- Minimal testing  
- Documentation minimal or missing  

---

# 🟦 **C. Final Mark Calculation**

**Total = Analytic (70) + Holistic (30) = 100 marks**

Teachers should use:
- Analytic marks for objective, criterion‑based scoring  
- Holistic band for overall engineering judgement  

This hybrid model supports:
- NESA moderation  
- consistent teacher judgement  
- clear feedback for students  

---

# 🟦 **D. Teacher Notes**

- Ensure students demonstrate *both* functional performance and engineering reasoning.  
- The holistic band should never contradict analytic evidence; it should refine it.  
- Use moderation notes to calibrate across classes or marking teams.  

---

# 🟦 **E. Moderation Notes**

- Check wiring diagrams for correctness and clarity.  
- Confirm algorithm logic matches Left-Hand Rule decision structure.  
- Review engineering logbooks for evidence of iteration.  
- Validate that documentation reflects actual robot behaviour.
