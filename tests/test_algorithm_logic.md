# Algorithm Logic Test
See: [Left-Hand Rule](ca://s?q=Explain_left_hand_rule_maze)

## Purpose
Verify that your maze-solving logic follows the Left-Hand Rule.

## Requirements
- Robot turns left when no left wall
- Robot turns right when front wall detected
- Robot moves forward when left wall present and front clear
- Robot handles dead ends

## Manual Test Procedure
1. Place robot in simple maze.
2. Observe decisions at each junction.
3. Record behaviour.

## Pass Criteria
Robot follows deterministic Left-Hand Rule correctly.
