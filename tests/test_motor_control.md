# Motor Control Test
See: [Motor driver basics](ca://s?q=Explain_H-bridge_motor_driver)

## Purpose
Verify that your motor control functions behave correctly.

## Requirements
- `forward()` moves robot straight
- `turnLeft()` rotates robot left
- `turnRight()` rotates robot right
- `turnAround()` performs 180° turn
- `stopRobot()` stops all motion

## Manual Test Procedure
1. Upload your code.
2. Place robot on flat surface.
3. Call each function individually.
4. Observe behaviour and record results.

## Pass Criteria
All functions produce correct and stable movement.
